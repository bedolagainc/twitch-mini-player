Mini Twitch Player — как запустить (Windows 10/11, 64-бит)
=========================================================

1. libmpv-2.dll рядом с плеером
   Положите файл libmpv-2.dll в ту же папку, где лежит twitch_mini_player.exe.
   Взять его можно из сборки mpv (https://mpv.io/installation/) — нужен именно
   libmpv-2.dll, а не mpv.exe.
   Без этого файла плеер покажет «libmpv-2.dll не найден».

2. streamlink
   Установите streamlink: https://streamlink.github.io/
   Проверка в терминале:  streamlink --version
   Если команда не найдена — добавьте папку streamlink в PATH либо укажите
   путь в консоли разработчика (кнопка «Консоль» в строке канала).

3. Запуск
   Запустите twitch_mini_player.exe, введите название канала и нажмите Enter.
   Колесо мыши — громкость, клик — пауза, двойной клик — полный экран.

Метаданные (тайтл, игра, зрители) — по желанию:
   https://dev.twitch.tv/console/apps -> Client ID -> поле «Twitch API»
   в консоли разработчика.

Субтитры (эксперимент 0.18.0): захват звука работает на Windows 11.
   Движок распознавания ставится скриптом scripts\fetch-whisper.ps1.
