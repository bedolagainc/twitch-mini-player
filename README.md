# Mini Twitch Player

Плеер Twitch-стримов в одном окне: без браузера, без Electron. Rust + `egui`,
видео через `libmpv`, ссылки HLS — через `streamlink`.
Локальные субтитры с переводом на русский: `whisper.cpp` + `opus-mt-en-ru`.

Windows 10/11, 64-бит.

## Установка

**Установщик (рекомендуется).** `twitch_mini_player-<версия>-setup.exe` из
[Releases](https://github.com/bedolagainc/twitch-mini-player/releases).
Ставится в профиль пользователя (без прав администратора), сразу с `libmpv`,
`streamlink`, распознаванием речи и переводом. Готово к запуску.

**Портативная версия.** `twitch_mini_player-<версия>-windows-x64.zip` оттуда же:
распаковать и запустить `twitch_mini_player.exe`. Всё нужное внутри.

Нужен только `Client ID`, если хочется видеть тайтл, игру и число зрителей:
<https://dev.twitch.tv/console/apps> → поле «Twitch API» в консоли разработчика.
Без него плеер работает.

## Возможности

- Нативное окно, кадр вписан с сохранением пропорций (чёрные поля, без растяжения)
- Качество: **«Авто»** (по замеренной скорости сети) или любой уровень текущего
  стрима; `audio_only` — ~0.2 Мбит/с вместо 6–8
- Колесо — громкость, клик — пауза (снятие с паузы прыгает к эфиру), двойной
  клик — полный экран видео
- Избранные каналы, индикатор «в эфире / не в эфире», метаданные Twitch
- Иконка в трее, скрытие окна в трей без рендера видео
- Заставка буферизации с секундами, самовосстановление потока
- GPU-декод и GPU-рендер включены по умолчанию: ~2 с ЦП за 12 с видео 720p
  (см. [docs/rendering.md](docs/rendering.md))
- Всё состояние сохраняется между запусками

## Субтитры с переводом

Всё считается локально: `whisper.cpp` распознаёт английскую речь, `opus-mt-en-ru`
переводит её на русский. Модели ≈ 190 МБ, интернет не нужен, ключей API нет.

Сейчас в консоли разработчика три кнопки: **«Записать 10 с в WAV»**,
**«Распознать 10 с»**, **«Перевести»**. Захват звука — только этого плеера
(process loopback, Windows 11), музыка из браузера и игры в субтитры не попадает.
Автоматическая строка субтитров поверх видео — в работе.

Подробности, установка моделей и ограничения: [docs/subtitles.md](docs/subtitles.md).

## Управление

| действие | результат |
|---|---|
| колесо над видео | громкость ±5% |
| одиночный клик | пауза / продолжить (с переходом к эфиру) |
| двойной клик | полный экран только для видео |
| `Esc` | выйти из полного экрана |
| клик по иконке в трее | показать/скрыть окно |
| правый клик по иконке в трее | меню: показать, играть/остановить, выход |

## Консоль разработчика

Кнопка **«Консоль»** справа в строке канала — всё техническое в одном окне:

- **Декодирование и отрисовка** — GPU-декод, GPU-рендер, профиль отрисовки
- **Диагностика** — строка статистики (FPS, буфер, режим декода, потерянные кадры)
- **Поток** — прямой HLS-URL, копирование ссылки, тайтл/игра/зрители
- **Twitch API** — Client ID
- **Звук и субтитры** — захват, уровень, запись WAV, распознавание, перевод
- **«Лучшие настройки»** — вернуть значения по умолчанию одним нажатием

## Где лежат данные

`%APPDATA%\twitch_mini_player`

| файл | что внутри |
|---|---|
| `settings.json` | канал, качество, громкость, настройки, геометрия окна |
| `favorites.txt` | избранные каналы |
| `models\` | модели распознавания и перевода |
| `capture.wav` | последняя запись для проверки захвата |

Файлы читаются «мягко»: отсутствующие поля берут значения по умолчанию, настройки
старых версий продолжают работать. Удаление программы настройки не трогает.

## Сборка из исходников

Нужен Rust (<https://rustup.rs/>) и Windows. Для запуска — `libmpv-2.dll` и
`streamlink` (установщик кладёт их сам; для сборки они не нужны).

```powershell
cargo build --release --locked
cargo test  --release --locked     # 27 passed, 5 ignored (живые тесты)
```

Проверка без Twitch — демо-поток:

```powershell
$env:TW_DEMO_URL = 'av://lavfi:testsrc=size=1280x720:rate=30'
.\target\release\twitch_mini_player.exe
```

Внешние бинарники для установщика собирает `scripts\fetch-vendor.ps1`,
установщик — `installer\twitch_mini_player.iss` (Inno Setup 6).

## Структура

| путь | что внутри |
|---|---|
| `src/main.rs` | окно, настройки, строка канала, консоль разработчика |
| `src/libmpv.rs` | загрузка `libmpv-2.dll`, Render API, свойства, события |
| `src/gpu.rs` | GPU-рендер: текстура OpenGL, шейдер, paint-колбэк egui |
| `src/subs.rs` | захват звука процесса (WASAPI process loopback) → 16 кГц моно |
| `src/asr.rs` | распознавание речи: `whisper.dll` + ggml-модель |
| `src/mt.rs` | перевод en→ru: MarianMT в ONNX Runtime |
| `src/tray.rs` | иконка и меню в трее |
| `docs/` | подробности: отрисовка, сеть, субтитры |
| `scripts/` | загрузка whisper, моделей перевода, внешних бинарников |
| `installer/` | Inno Setup: `setup.exe` |

## Версии

`Cargo.toml` → `env!("CARGO_PKG_VERSION")` → консоль и трей. Каждое изменение —
запись в `CHANGELOG.md`. `patch` — исправление, `minor` — новая функция,
`major` — ломающее изменение. Релиз на тег `v*` собирает CI: `setup.exe` и
portable zip.

## Диагностика

- Паника: `%TEMP%\twitch_mini_player_crash.txt` (версия, текст, backtrace)
- Подробный лог: `TW_DEBUG_LOG=1` → `%TEMP%\twitch_mini_player_debug.txt`
